Serving size vs calories, 98 menu items from 7 restaurants

Each marker is one menu item. Position shows serving size (x) and calories (y); color shows the restaurant type and the shape tells restaurants of the same type apart. The dotted lines connect items with the same calories per 100 g (100, 200, 300 and 400): the higher a marker is above a line, the denser the item. The first panel shows all restaurants; the other panels show one restaurant each, on the same axes.
