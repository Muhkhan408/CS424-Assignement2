Run it on Google Colab

Colab already has pandas, numpy, matplotlib, seaborn, plotly and openpyxl, so there is nothing to install. The notebook reads DataDictionary.xlsx from the folder it runs in, so the Excel file has to be next to it.

To run and see each visulization: upload the two files (simplest)
Go to colab.research.google.com and choose File > Upload notebook. Upload notebooks/Assignment_2.ipynb.
Open the folder icon in the left sidebar. Drag DataDictionary.xlsx (from data/raw/ or notebooks/) into the file panel, so it sits directly in /content next to the sample data folder. Do not put it in a subfolder.
Choose Runtime > Run all.


Note: 
All the iterative plots and visulization are saved in folders with their associated tasks with task 7 containing the final.
Assignment_2.ipynb - the orignal code as jynyper
DataDictionary.xlsx - orignal data set
corrections_log.csv - corrections of rows with invalid values
menu_clean.csv - Cleaned data set as csv
